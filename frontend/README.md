# My Exam Template

โปรเจกต์แม่แบบสำหรับการสอบ Full-stack Web Development

## 🚀 วิธีการรัน Backend

1. เข้าไปยังโฟลเดอร์ backend:
   `cd backend`

2. ติดตั้ง Dependencies:
   `npm install`

3. สั่งรัน Server:
   `node server.js`

## 🌐 วิธีการรัน Frontend

เปิดไฟล์ `frontend/index.html` บน Web Browser
